<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CSV file/paste → DOM | User-supplied CSV values rendered into preview table — XSS risk |
| CSV role/suffix → ActionScript parameter | Role and suffix strings embedded as ActionScript parameter values — injection risk |
| B64 chunk parameters → PowerShell | Chunk data decoded on client — malformed data risk |
| GetRelevance result → DOM | Analysis property values (UserID, Role) rendered to analysis table — XSS risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-01 | Spoofing/Tampering | CSV-derived values (user, computerID, role) written to DOM in renderPreview() and loadAnalysisView() | mitigate | htmlEscape() wraps EVERY value before innerHTML assignment. Verified in Task 2 acceptance_criteria check: grep for 'htmlEscape(row.user)' and 'htmlEscape(row.computerID)' and 'htmlEscape' in Analysis render. Pattern established in all prior dashboards (fixlet_dispatcher.ojo). |
| T-4-02 | Tampering | PowerShell injection via role value in ActionScript parameter "Role"="..." and suffix in action title | mitigate | Two-layer defence: (1) validateRows() blocks any role not in PORTAL_CONFIG.roles before deployAll fires; (2) deployAll() re-validates role against PORTAL_CONFIG.roles before calling buildAssignActionScript. xmlEscape() applied to role and title in buildAssignActionXml. Suffix value is admin-entered free text — xmlEscape() applied; double-quote characters in suffix stripped or rejected (RESEARCH.md Pitfall 3: B64 has no quotes; role/suffix do need explicit quote-stripping). |
| T-4-03 | Tampering | Malformed Base64 chunks causing PowerShell decode failure | mitigate | chunkCount parameter is the JS-computed array length, not user input. PowerShell script wraps ConvertFrom-Json in try/catch with meaningful exit code. Client-side relevance guard (DB-existence) runs before PowerShell — unintended clients won't reach the script. |
| T-4-SC | Tampering | npm/pip/cargo installs | accept | No packages installed — BigFix built-ins (API.Post, GetRelevance) and browser built-ins (btoa, FileReader, JSON) only |
</threat_model>
