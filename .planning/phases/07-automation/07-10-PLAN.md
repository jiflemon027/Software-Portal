<objective>
Execute the file-moving half of D-15: relocate the retired dashboards, scripts, modules, BES
template and config files into `archive/` subfolders, relocate the test suites whose subjects
moved, re-base their paths so the frozen snapshots still work, and write the archive README.

Purpose: D-15 says archive, not delete. Moving with `git mv` keeps the retired Axonius
reference-DB design readable and blame-able while taking it out of the default test run and out
of a future reader's mental model of "what is live".

**Split note.** This plan was previously a single three-task plan that also stripped dead
references out of live code and rewrote the admin docs (~31 files). It was split at revision time
on scope grounds: those two tasks are now plan **07-11**, which runs in the next wave and depends
on this one. Nothing about the wave position of the phase's later work changed — the UAT
checkpoint that used to be 07-11 is now 07-12.

**Plan-time decision recorded here (resolves RESEARCH.md's open question and 07-VALIDATION.md's
Wave-0 item).** The suites whose subjects are archived move to `tests/archive/{unit,pester}/` as
**frozen snapshots** — not deleted, and not left in the default run. Deleting them discards real
coverage of code that still exists in the tree; leaving them in `tests/unit`/`tests/pester` means
the "full suite green" gate keeps asserting behaviour of a retired design. A
`tests/archive/README.md` records that they are historical and unmaintained.

Output: every retired artefact under an `archive/` folder with history intact, and a default test
run that no longer discovers them.
</objective>
