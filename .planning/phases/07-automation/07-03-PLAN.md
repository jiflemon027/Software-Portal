<objective>
Automate the content half of the portal: scan the configured source sites for newer versions of
products already in the Dereso Software Portal site, copy the approved ones with their category
and role metadata intact, stamp the superseded portal fixlet, and pre-stage the installer
downloads in the Custom Repository so the Dispatcher's prefetch rewrite resolves.

Purpose: this converts the `fixlet_update_tracker.ojo` button-driven loop (Phase 6) and the
`fixlet_copier.ojo` copy sequence (Phase 1) into scheduled server-side scripts, and it makes the
Dispatcher's `rewritePrefetchUrls()` output actually resolvable by pre-placing the files.

Intent is UNCHANGED from the superseded 2026-08-01 design (old D-09 / D-10 / D-11 / D-16). Only
the table names move: `ContentCache` (was `CacheEntry`) and the shared `SyncRun` table with a
`Type` column, per the 07-RESEARCH.md discretion resolutions.

Output: `scripts/ContentSyncCore.psm1`, `scripts/Invoke-ContentSync.ps1`,
`scripts/Stage-Repository.ps1`, two more task rows in `scripts/Register-AutomationTasks.ps1`
with their exported XML, and two Pester suites.

Scheduling note: this plan touches NO file that 07-01 or 07-02 touches except the additive task
table in `scripts/Register-AutomationTasks.ps1`. If that file has not yet been created by 07-02,
create it here with the same data-table structure and let 07-02 append; the two plans must agree
on the table shape. Given zero other overlap, this plan may be executed concurrently with Wave 1.
</objective>
