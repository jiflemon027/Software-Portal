<objective>
Build the D-16 read-only Analysis tab: a table of what is actually in `RoleAwareness.db` across
the fleet (`mapped_users`, `map_source`, `map_region`), plus a reconciliation panel comparing
the roles' configured username lists against those live mappings.

Purpose: D-16 exists specifically to catch the failure mode this model is most exposed to — a
username typed into a role that never matches a real logged-on user, so the role silently never
lands. The retired `fixlet_role_assigner.ojo` had this view; D-14 folds it into the new
dashboard before that file is archived.

D-08 is honoured here and nowhere else: `Region` survives purely as a **reporting** column read
from the existing `map_region in r.db` property. There is no region picker, no region table and
nothing region-based in any targeting path.

Output: the Analysis tab and its unit coverage.
</objective>

"Configuration and fleet state agree." Call `loadAnalysisView` from `switchTab` when the
Analysis tab is selected, and once from `initDashboard` after `loadKnownUsers`.

Read-only guarantee: this tab issues no `API.Post`, no `API.Put`, and no `API.Delete`.
