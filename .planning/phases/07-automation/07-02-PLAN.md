## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Source BigFix sites → Invoke-ContentSync.ps1 | Source fixlet XML from external BigFix sites is untrusted; fixlet name and category values flow into SQL and XML |
| Source fixlet URLs → Stage-Repository.ps1 | Prefetch URLs from portal fixlet ActionScript flow into Invoke-WebRequest; SHA1 must be verified before staging |
| Registry → Stage-Repository.ps1 | Registry DataDirectory value used to construct staging path; tampered registry → wrong path |
