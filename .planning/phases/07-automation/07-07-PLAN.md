<objective>
Build the two Publish prerequisites that must exist before any policy action can usefully run:
(1) staging `scripts/Assign-RoleMapping.ps1` into the root server's Custom Repository at the
exact path, SHA1 and size that `bes/Assign-RoleMapping.bes`'s prefetch block pins, and (2) the
per-role Task find-or-create that turns the template into one concrete `Assign Role Mapping -
<role>` Task in the custom site.

Purpose: `bes/Assign-RoleMapping.bes` prefetches
`http://127.0.0.1:<port>/Uploads/CustomRepository/SoftwarePortal/rolegroups/Assign-RoleMapping.ps1`
with `sha1=69860a1239e4509dce483a07523ea07e26764279 size=8877`. If that file is absent or a
single byte different, **every endpoint's action fails at the prefetch stage** and no role is
ever mapped — and nothing in the repo currently puts it there. This plan closes that gap and
makes the pin machine-checked, so a future edit to `Assign-RoleMapping.ps1` without re-pinning
the template fails CI instead of silently breaking the fleet.

Output: a "Stage endpoint script" action, the per-role Task generator, and unit coverage that
pins the mirror to the template's SHA1.
</objective>

- Relevance: `true`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dashboard → root server Custom Repository | Writes a PowerShell file that every managed endpoint will later download and execute |
| Custom Repository → every endpoint | The prefetch SHA1 is the only integrity control on that download |
| dashboard → `fixlets/custom/<site>` | Creates BES content the whole fleet may act on |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-07-01 | Tampering | A modified `Assign-RoleMapping.ps1` being staged and executed fleet-wide | mitigate | BigFix's own prefetch `sha1=`/`sha256=`/`size=` verification rejects any file that does not match the pin; Task 3 asserts the repo script, the template pin and the dashboard mirror all agree, so an unreviewed edit fails CI before it can be staged. |
| T-07-07-02 | Tampering | ActionScript injection through the staged script body | mitigate | The body goes through `escapeActionScriptBraces` (double `{` only, SKILL.md §2); `{parameter …}` and `{value "wwwRootFolder" …}` substitutions stay outside the createfile block; unit-tested for `{{` present / `}}` absent. |
| T-07-07-03 | Tampering | Writing outside the intended repository subtree via a crafted path | mitigate | The destination is derived entirely from the `wwwRootFolder` registry value plus a hard-coded `Uploads\CustomRepository\SoftwarePortal\rolegroups` suffix — no operator input contributes to the path. |
| T-07-07-04 | Tampering | 400 Bad Request / silently corrupt Task from in-place XML mutation | mitigate | `buildRolePolicyTaskXml` builds a fresh document in SKILL §7 schema order; acceptance criteria forbid DOM mutation of fetched BES documents. |
