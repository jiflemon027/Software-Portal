<objective>
Build the daily ingest: stream the Axonius export into `AutomationState.db`, resolving each
user to a single lowercased match key, defensively parsing the loosely-aligned multi-valued
group columns, resolving entitlements through the `GroupRoleMap` rule table, and marking
anything no longer present as `Active = 0`.

Purpose: this is the only place the external world enters the role pipeline. Everything
downstream (snapshot, policy action, endpoint reconcile) is a projection of what this script
writes. It is also the only genuinely new algorithm in Phase 7 — every other component has a
proven in-repo analog.

Output: `scripts/AxoniousParse.psm1` (four pure functions, the test seams), 
`scripts/Import-AxoniousExport.ps1` (the streaming driver), and three Pester suites.

Task subdivision follows the 07-RESEARCH.md discretion resolution: (a) reader + header
validation + stale-file guard, (b) per-row transform, (c) GroupRoleMap matcher + batched
upsert, (d) age-out + run finalisation. The pure functions live in a separate `.psm1` so they
are importable by Pester without executing the driver.
</objective>

scripts/AxoniousParse.psm1 exports:

  Resolve-UserName -Sam <string> -Upn <string> -UserName <string> -Priority <string>
    returns [pscustomobject] @{ UserID = <lowercased key>; Username_Src = 'sam'|'upn'|'username' }
    $Priority defaults to the PipelineConfig UsernameSourcePriority value 'sam,upn,username'.
    Returns $null when every candidate is blank.

  Get-GroupViews -Raw <string>
    returns [pscustomobject] @{ dn = <raw>; cn = <first CN= RDN if the value matches ^CN= else raw>; display = <supplied separately or the raw value> }

  Get-SourceType -GroupType <string> -Email <string>
    returns 'Mailing List' when $Email is non-blank, else a normalised label derived from
    $GroupType ('AD Security Group' | 'Azure AD Group' | 'Distribution Group' | 'Unknown').

  Resolve-Roles -GroupViews <hashtable> -Rules <object[]>
    $GroupViews has keys cn / display / dn. $Rules are GroupRoleMap rows.
    Returns zero or more [pscustomobject] @{ Role; GRMID; Match_On; Matched_View }.
    Match semantics: rule inactive (Active=0) never fires; Pattern ending in '*' is a
    case-insensitive prefix test against the view named by Match_On; otherwise exact
    case-insensitive equality. ALL matching rules apply (Priority is advisory ordering only).
